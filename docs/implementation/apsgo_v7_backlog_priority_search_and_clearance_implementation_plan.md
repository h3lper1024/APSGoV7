## 2. 核验基线与保护

### 2.1 已确认口径与当前实现的区别

- 既有：起排时间显式传入，六月样本为 6 月 1 日零点；截止为交期当天 24 点；虚拟材速度 100 米/分钟；原订单最后拆片完成才算整单完成。
- 既有：只允许链重低于下限的最终偏差，禁止、来源守恒、拆单及期锁不放松；正式零欠重门不改。
- 当前代码及第一步对照：欠重第 3/4 位，新增晚交吨位和累计负担第 5/6 位；后置精修欠重数量和缺口分别不增加。已撤回的旧“交期优先”实验并非本次方案，不能直接恢复其代码或历史结果。
- 本次已确认的新九级：禁止数、禁止严重度、旧欠全部完成用时、累计等待与延期负担、欠重链数、欠重缺口、链间宽差、虚拟重量、链数。新增晚交原订单吨位仅统计，不参与评分、同分裁决或隐藏接受门槛。
- 旧欠清空优先于本月延期改善，两项交期目标优先于欠重；新模式取消独立的欠重数量/缺口分别不增加拦截，按完整新九级比较。允许高层目标改善带来更多欠重或新增晚交吨位，仍须满足禁止性规则与最终审计，正式零欠重门不放宽。
- 评分口径确认不等于已实现或正式启用；用户已授权按本计划实施，阶段 4 才接线新评分，不再重复询问已经确认的优先级取舍。
- 不增加“全部旧欠必须先于全部本月订单”硬规则，不将旧欠重新混入新增晚交吨位。

1. 核对当前分支、HEAD、差异及原五个运行产物哈希，不重新生成或覆盖历史基线。
2. 从原最终方案输出 96 单旧欠的原编号、原吨位、片段位置和完成时间，并保留本月全部原单明细。
3. 分别复现设计第 2.3 节两个有效节点前移，保存动作参数、原/新有序计划和评价、实际预算计数及核心审计；明确两例分别从相同原方案出发。
4. 保存旧枚举中样例原单和成功动作的次序；确认本专项第一步使用 4 提案/原单、64 提案/动作类的初始工程试验值。

完成标准：源数据和代码身份可追溯，两例在原完整接受入口被接受且核心审计通过。若不能复现，先定位差异，不用新增评分掩盖，也不把上一轮自然语言诊断当作可运行证据。此阶段不要求重跑 821 秒的完整基线。

### 阶段 1：原订单顺序与小批枚举

1. 在现有排序位置区分三组原订单；旧欠使用最后片段完成时间降序，同分稳定。
2. 在原五类动作生成器中按原订单小批继续，较早目标链优先且目标链间轮转；保留移动/交换、片段长度与后续位置覆盖。
3. 写入相应小例测试，但本阶段只做差异与语法级检查；业务执行集中阶段 2。

完成标准：只改“候选从哪里来、何时轮到”，不改九级声明、已有动作构造、工时、预算或接受保护；无交期、无旧欠两种路径不被误接到新轮转。

### 阶段 2：动作轮转、续访和第一步集中验证

1. 把交期且有旧欠的扫描改为有界动作类轮转；每次接受后切到下一动作类和原单访问起点，不能所有队列复位。

3. 覆盖到尾回绕、拒绝后继续、完全穷尽、时间/候选截止、取消和桥接追加耗费；自然结束不能依据旧方案的穷尽状态。
4. 集中运行第 6 节第一组测试；在冻结最终方案上自动枚举到两个样例动作，记录首次发现所需提案/检查数，与旧序比较。不得通过生产订单白名单直接调用成功位置冒充自动搜索。

完成标准：轮转和完整接受正确，样例机会显著前移的证据可回读，旧七级及无旧欠路径回归通过；规则和当前九级评分保持。若没有解决样例机会问题，先修第一步，不进入完整性能结论。

### 阶段 3：仅改善搜索的完整对照

完成标准：得到完整、可审计的第一步结果并作采用/取舍判断，而不是必须给出正收益。若禁止或守恒失败，修复后另目录重测；若欠重、新增晚交吨位等变差，按设计第 7.2 节暂停讨论，不悄悄调参数或跳到下一目标“补救”。

### 阶段 4：旧欠优先九级及完整接受接线

1. 新增最大值派生，使用原订单完成映射、`d_i <= 0` 分类和无旧欠取零；不改变计时和旧累计负担。

4. 核对 `chain_order_objective_index()` 及所有调用者，定位实际参与评分的新交期指标；仅新模式取消独立欠重不增加、原前四项必须相同等冲突拦截，复用完整候选、允许偏差检查和新九级严格比较。
5. 报告增加清空小时并区分评分与统计；按名称核对完整评价，晚交吨位即使不在质量序列里也须按原公式复算核验。核心无缓存审计、应用绑定检查复用既有入口。
6. 集中执行第 6 节第二组测试；检查所有读取质量序列的调用者，特别是按下标计算正式欠重门的工具，不让九项同长度掩盖语义变化。

完成标准：原九级和旧欠优先九级按有序指标键与指纹显式区分；目标和统计值、空集/拆片等边界正确；新优先级不再被旧欠重保护抵消，晚交吨位无隐藏参与。没有改数据库、HTTP、YAML、原订单或额外引入重算全节点的循环；新顺序在完整搜索各阶段生效，不伪装成仅改展示。

### 阶段 5：第二步独立对照与重复性

1. 同样输入与预算运行旧欠优先九级，保存独立目录；与阶段 3 比较整组评分/接受变更效果，同时保留原九级基线供三组汇总，不声称分离出单个新增目标的收益。
2. 按指标名称比较；三个版本只读派生清空小时并按新顺序投影作偏好对照，不直接比较同为九项但语义不同的原始质量元组，也不覆盖旧评价或发布指纹。晚交吨位明确为统计列，正式欠重门按指标名称读取。
3. 新模式若未被时间截断，额外重复一次，核验有序方案、业务指标、轨迹、候选/评价/接受次数和停止原因；耗时、时间戳等运行元数据不要求字节相同。
4. 若时间先到，明确记录无法按同候选工作量判断确定性，不无限重跑或自动扩大预算；是否另做试验再讨论。
