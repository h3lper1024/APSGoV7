## 5. A0：冻结基线与构造见证

### 工作内容

获准实施后重新确认分支 HEAD、实际运行环境和依赖，读取源码及工作区差异。固定原构造的图、覆盖、链序、质量、提前明细与计数。审阅 `construct_numeric_initial_plan()` 到 `solve_numeric()` 的接口，确保新行为确实进入当前整数数值路径。

准备设计第 3.1 节同期间两链案例，以及链内阻塞、全未就绪、混合期间和停用规则案例。真实数据只使用用户已有合法输入或另行明确提供的数据；缺少最早时间、重量口径或活动规则快照时先记录缺项，不填假值、不擅自读取/修改现场库。

按实际输入记录代码 SHA、输入/规则/字典/原型指纹、种子、时间/候选预算、开始时间、重量语义、有效速度及来源。不照抄 README 的 40 万次/310 秒，也不把历史运行记录当作当前现场设置；对照参数取冻结事实，不为本专项改 YAML。

### 交付与退出门槛

形成专项见证及基线清单，明确提前是初始已有还是后续引入。测试预期由手算/原实现建立，不能运行新算法后将其输出反写为期望。已有失败（特别是回写政策与旧测试差异）单列，不能静默改测试使基线全绿。没有可用真实数据不阻塞小例开发，但 A4 保持未验收。

## 6. A1：链就绪阈值辅助

实现内容为设计第 3、7 节的 `D(L)` 与 `R(L)` 数值扫描，复用既有列访问、源索引、工时、溢出状态与分步取消风格。函数名称按项目代码风格确定；不新增日期解析、独立评分程序或专属对象图。

必须覆盖：链首已就绪但后继未就绪、后继在轮到时就绪、真实过渡材、虚拟材计入前缀、负偏移、精确相等、提前 1 毫秒、缺失下界、错误来源索引和整数溢出。全部虚拟链不得被新辅助判定为合法生产链。

固定种子生成小例，以独立逐节点算法和 `_clock_view()` 对照阈值判定。使用原始整数毫秒，不先按显示秒舍入。退出门槛是上述专项通过且不修改既有时钟/违规公式；辅助测试通过不代表接线或业务效果完成。

建议提交单元：`#feat 增加初始链最早开工阈值数值辅助`。

## 7. A2：整链就绪布局与完整比较

### 工作内容

在现有初始构造完成期间分组和基准完整评价后，仅为启用最早规则的请求进入新分支。保留基准链及评价；预计算摘要，按设计第 5 节执行当前期间稳定扫描、就绪整链优先和无就绪时原顺位退路。每输出一条链仅推进真实工时。

用 `NumericChainView`/现有重排能力生成完整候选，验证链内数据及身份、来源、重量、覆盖和期间不变。执行同一完整评价：非最早规则数量不增且原质量键严格改善才采用新方案，否则原样保留基准。相同时不得为了“启用了优化”而换一个等价初始排列。

新增任务内汇总，区分基准、时间提案和最终选用初始方案，记录选择原因、调序数量、阻塞退路、扫描与耗时。不得修改公开请求、结果枚举、`RunManifest` 必填字段或为诊断引入新的评分身份。

### 验证与退出门槛

用例验证同期间选择、每链后重新计算可选集、期间不越界、跨期不重置、全未就绪仍终止、方案更好/相同/更差和保护拒绝。设计手算案例必须不增加链或虚拟重量并消除指定提前；全部从开始均就绪时保持旧方案。

检查 `candidate_check_count`、初始搜索代次、已接受动作/虚拟/拆单计数不因构造增加。预算取消/超时保持原中断返回契约；不因已存在内存基准就伪装自然完成。任何新输入/数值异常不得被“质量不佳回退”吞掉。

建议提交单元：`#feat 初始构造按最早开工时间进行同期间整链调序`。

## 9. A4：真实 A/B 对照与质量验收

A 组为固定原构造，B 组为阶段 A。**两组都启用相同最早开工规则**，仅构造变化；额外停用组用于兼容性检查，不得充当算法效果基线。用固定代码导出或测试工具隔离对照，不给生产新增随意切换旧/新算法的公共参数。

两组使用同一订单集合、订货量或其他已确认重量口径、最早时间、速度、开始时间、规则/字典/原型快照、种子和完整预算。新增构造时间计入原预算，不另给 B 组更多搜索时间。实际消费数和停止原因可能不同，必须披露；冷启动与热运行分列，禁止用热 B 对比冷 A 声称性能提升。

## 10. B0 / B1：必要分段的后续门槛

只有残余案例表明“可就绪完整链不足、内部连续片段可利用”，且用户确认继续扩大范围，才进入 B0。设计第 6 节是方向，不是声称完整分段策略已经冻结。

B0 必须补齐：前缀与内部片段的枚举顺序、确定的扫描上界与截止检查、片段完整性/链重准入、原单期锁及新链身份、归属变化队列、每份残余片段的处理，以及相对于基准/阶段 A 的完整比较。不得留下“必要时随意切分”作为可执行规则。

B1 只做订单序列连续分段，不改变订单重量或建立受控拆单谱系，不拼接未检查断口，不增加耗时虚拟材。用例必须覆盖 `A→B→C` 取出 B 后残余分离、纯后期片段返回后期队列、不得产生早于已封闭期间的片段、欠重增加被正确评价、无可用片段时仍有有限退路。

完成专项后增加 C 组，与 A/B 同输入、同规则、同预算对照；新增链、欠重和虚拟重量必须单列。未证实分段收益则保留阶段 A，不以扩大复杂度代替效果。Issue 第三/第四点继续独立规划。
