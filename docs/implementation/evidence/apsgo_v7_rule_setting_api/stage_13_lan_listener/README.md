# 阶段 13：允许其他电脑访问规则服务

## 1. 基线与用户确认

- 日期：2026-09-07。
- 平台：macOS，Darwin 27.0.0 arm64。
- 分支：`codex/rule-setting-api-integration`。
- 实施前提交：`0ec86f85a0303a59dd0df8a8676d19e142bc61b6`。
- 实施前工作树：用户已将 `config/apsgo_v7_service.yaml` 的 `listen_host` 修改为 `0.0.0.0`；本次保留并实现该修改，不覆盖为旧值。
- 用户确认：其他电脑必须能够访问规则服务，`listen_host` 允许填写 `0.0.0.0`，本次不把登录鉴权作为实施前置条件。

## 2. 实施范围

- 默认 YAML 使用 `listen_host: 0.0.0.0`。
- 配置加载器只接受 `127.0.0.1` 或 `0.0.0.0`；其他主机值继续在启动前拒绝。
- 服务默认监听常量同步为 `0.0.0.0`。
- C# 配置键保持 `BACKEND_ALGORITHM_URL`；跨机器时填写服务端实际局域网 IP，不填写 `0.0.0.0`。
- 不修改端口、数据库、HTTP 路由、规则、求解器或 C# 代码。
