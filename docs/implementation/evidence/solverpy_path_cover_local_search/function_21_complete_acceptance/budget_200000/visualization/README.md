## 内容与口径

- 全部 553 个排程节点，不抽样：531 个原订单拆分后为 533 个真实节点，另有 20 个虚拟节点。
- 三张共享顺序轴曲线：宽度（mm）、厚度（mm）、均热段允许温区上下限（°C）。温区不是实际炉温；虚拟温区是生成时从锚点派生的记录值，不是新增工艺设定。缺失值不补零；本次四项物理字段均完整。
- 22 个小辊期按已发布结果的链序编号为 01～22。保留链内和链间导出序，不按大辊期重新排序；边界处断线，避免把两条链画成可直接连接。全局横轴不是生产时间轴。
- 每链总重量包含真实片段及虚拟材；统计图分别显示虚拟材个数和重量，真实过渡材仍计入真实订单。
- 交期数量按 `source_order_id` 全局去重；交期重量按实际排程片段累加，虚拟材无交货日期，不参与交期分布。逐链日期图显示吨数，悬停显示本链原订单数；不同链的局部去重数量不能直接当作全局数量。
- 当前仅展示订单交货日期分布，不计算完工时刻、日历或延期风险。输入有 5 月 31 日交货订单，并不在此报告中自动判为逾期。
