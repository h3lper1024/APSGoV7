# 阶段 4：增量复用、独立审核与边界接线执行记录

## 1. 子项 4.1：同标准数值增量与缓存复用

- 实施前提交：`a0d5c03`。
- 候选评价仍调用第 2.2 阶段建立的同一数值规则、资源、时钟和九级汇总函数，不引入旧对象评价或另一套近似评分。
- `NumericChainFacts` 以只读 `int64` 数组保存逐链总重量、工时、真实材重量、虚拟材重量和未来借用重量。稳定链标识、所属期和有序节点行完全相同时复用；任一条件变化即重算该链。
- 未变链规则结果按相同条件复用；链换序时仅重定位违规记录的链下标。连续段、逆宽基准和跨虚拟端点等链级规则不会拼接局部中间值，变化链始终整链重扫。
- 全局真实材、虚拟材、借用及虚拟比例从最新逐链摘要汇总；计划期延后和相邻链首尾宽差仍由同一方案级规则入口读取当前结构，避免缓存旧链序。
- 交期时钟先识别最长相同节点前缀和后缀：前缀完成时刻可直接复用；后缀仅在节点序列相同且进入后缀前的累计工时也相同时复用，否则从最早变化位置继续累计。全部原单最后片段位置由新 `NumericPlan` 重新建立，再计算完成、晚交和等待负担。
- 同一任务与规则下，节点优先级统计直接复用。任务对象、规则程序或九级目标身份变化时保守执行完整的新数值评价；不会回落旧求解器。旧评价的方案身份、代次、链数、节点完成数组或原单完成数组不匹配时明确拒绝。
- 本阶段没有增加“前缀快速拒绝”；因此不存在未计算列按零参与接受。完整候选仍在唯一接受点按完整九级数值比较。
