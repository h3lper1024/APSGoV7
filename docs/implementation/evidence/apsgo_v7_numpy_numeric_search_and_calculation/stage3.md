- 实施前提交 `72b3d31`。新增私有数值构造模块，直接读取 `NumericTask` 和 `NumericRuleProgram`；构图过程中不恢复订单对象、不调用旧规则对象、不写正式资源或编号。
- 构造图使用 `ordered_rows`、`adjacency_offsets`、`adjacency_rows` 三个只读 `int64` 数组。`adjacency_offsets + adjacency_rows` 是压缩邻接表：每个节点的可连接后继在一个连续区间内，避免用节点标识字典承载搜索图。
- 主排序仍为宽度降序、构造优先级、厚度、最低温度；后继排序仍为厚度差、重量降序、构造优先级。区别是物理量和权重直接比较精确整数，不再投影为浮点数，也不再保留构造方向的 `1e-9` 隐式余量。
- 最大匹配继续采用分层广度遍历和非递归增广路径，主次序及后继次序稳定；结果用整数后继数组和路径偏移表达。初始方案继续只做直接追加或切链，不生成虚拟材、不拆单、不消耗候选额度；链重上限和禁止轮廓使用已编译整数规则，最后执行一次全量九级评价。
- `NumericPlan` 新增结构身份，覆盖任务、节点序、链边界、链标识、所属期及由这些结构派生的节点/原单位置数组，不把方案代次混入结构身份；全量评价同时绑定该身份，避免相同代次或错误派生位置误配另一方案。
