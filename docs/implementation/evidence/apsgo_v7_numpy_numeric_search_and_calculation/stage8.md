## 2. 已实现内容

| 内容 | 实现与验证边界 |
|---|---|
| 扁平输入 | `_numeric_batch.py` 将节点、链、候选、变化链和资源尾部整理为只读数值数组；默认 8 条结构描述，保留每描述最多两种修复尝试 |
| 唯一评价内核 | `_numeric_kernel.evaluate_batch_kernel()` 的编译串行循环调用同一个 `evaluate_kernel()`；没有逐候选 Python 完整评价和第二套评分公式 |
| 输出隔离 | 九级评分、错误位置、链事实、规则命中、时钟、原单完成/晚交/等待和扫描计数按候选偏移隔离；拒绝候选不生成明细对象 |
| 资源隔离 | 私有虚拟材/拆片映射到不相交行区间，保留谱系、用途、期锁；正式序号只在接受时确认 |
| 原序消费 | 首改善仍由主线程按原序接受；两次修复分别在实际尝试时扣额；第一项接受后剩余结果作废；未消费的错误不抢先中断前序候选 |
| 容量与取消 | 单次扁平调用最多 64 个完整候选，数值缓冲保守估算上限 32 MiB；超限缩批，单候选超限用同一单候选内核，不换求解器。准备、编译调用边界和消费时检查取消 |
| 范围保留 | 候选生成、覆盖准备、预算与接受仍在 Python；首轮搜索及拆单流程不改成批量。未启用线程、`prange` 或多进程 |

32 MiB 只限制本次扁平缓冲估算，不是整个进程内存上限；共享目录、私有候选构造与编译器内存另外存在。未变链仍由同一内核核验链身份、期和节点数组后复用，变化链索引不用于跳过核验。
