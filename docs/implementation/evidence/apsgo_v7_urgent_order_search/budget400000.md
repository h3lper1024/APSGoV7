首轮合计 303785 次候选后自然结束，总阶段约 180.441687 秒。之后执行 **2 次同期间拆单**，修复了此前 1170.3 吨窄钢连续重量禁止项；无未来拆单。拆单与一次回放共约 13.637187 秒，在回放中达到 40 万上限，**后置定向精修仍未执行**。所以额度不足确实是上次无法完成必要修复的原因之一，但本轮也没有走完所有优化阶段。

CPU/经过时间约为 99.7%，不是主要在等待。主要计算时间为整链交期排序的 43788 次完整评价；单节点枚举则耗检查额度多、进入完整评价少。进一步提高候选不保证线性提质，也可能先触及 300 秒时限，本轮不自行再提高。
