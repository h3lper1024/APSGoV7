## 2. 回收核对：毛回收量不是最终节省量

后置入口虚拟材 460 吨；接受过程中删除普通连接材 50 个 / 1000 吨，同时新增 68 个 / 1360 吨；最终为 `460 - 1000 + 1360 = 820` 吨。过程允许删除本阶段先前新建的连接材，各节点只删除一次。

逐次增删与真实前后完整方案、接受动作轨迹及重量均已闭合。生成序号上界从 27 单调到 95，没有因删除最大存活节点而回退或复用。分隔材、填充材和真实材料不在删除清单；独立最终核心与应用审计仍通过。

最终虚拟重量与仅调度组相同，比原代码多 240 吨，因此**不能声称此实现已经降低最终虚拟材消耗**。回收的已验证作用是允许结构调整换掉失效接口并打开新的合法改善路径。
