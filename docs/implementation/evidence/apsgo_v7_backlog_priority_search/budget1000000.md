## 6. 新发现：极小时间差影响了接受决策

精确读取 2547 次轨迹发现，**87 次接受的前两项禁止指标相同，旧欠清空只减少了 `1E-25～2E-25` 小时**；其中 67 次累计等待与延期负担反而增加，19 次欠重链数增加。87 次中包含 21 次切链。示例：

- 第 47 次整链排序，清空 `554.0501654228165877213707082→554.0501654228165877213707080` 小时，累计负担却 `1852208.315593→1853797.087230` 吨·小时。
- 第 52 次整链排序，清空仅减少 `1E-25` 小时，累计负担却 `1842037.762335→1893388.927925` 吨·小时。

当前精确逐级比较把这些极小时间差放在累计负担前，因此接受上述动作。它们不应被宣传为有实际生产意义的时间改善；应另行核查时间汇总与比较精度，明确如何处理等价时间。**本轮只记录现象，不调整精度、容差或目标公式。** 也不能将全部 170 条链归因于此：其余切链可能有实质交期收益，影响大小还需隔离复测。
