- `NumericCandidateDescriptors` 只接收只读连续整数记录，包含动作、链身份、节点/区间、方向、原订单拥有者和修复变体；绑定实际任务及方案代次。字段授权仍交候选计算，不在传输层重写算法。

- `NumericCandidateWorkspace` 只有单次候选私有字段尾部、变化链、模板行、拆分组和分步资源事件边界；字段名/类型从现有权威列派生，含所有分类/有效掩码/规则派生列，不新建另一套业务字段定义。
- 容量检查不修改缓冲、额度或随机源。容量重试重新从同一基准分配私有区；重置/扩容提升内部有效代次，旧借用视图失效。任务或正式方案变化后必须换工作区，不能跨候选共享可写尾部。
- `NumericSearchAction` 原枚举移动至公共状态模块，搜索原导入名继续指向同一类；原字符串及顺序未变。原六个计算状态码也移到该层，评价内核导入同一权威定义，未改公式、返回值或业务身份编码。
- 未引入新模块/依赖，不放宽架构保护；未开始资源派生、候选计算、主流程接线或线程。私有容量由调用者按实际动作界定，不用 531/40 万作为生产容量。
