## 1.2 公共链操作与代次索引

实施前 `44c426c`，1.1 已独立提交。新增 `_numeric_chain_ops.py`，不依赖搜索阶段、规则、评分或资源业务对象：

- 原方案及变化链共用 `chain_rows()`；`write_parts()` 用有序数组片段统一拼接，先完成参数与容量检查再写入。拒绝或容量不足不改变有效区及链映射。
- 反向、插入/删除、链内/跨链移动、区间交换、合链只写变化链；切链和整链换序只改小型链映射，保留原节点片段引用。空链保留为临时结构，调用者显式压缩，不在基础操作中暗加业务政策。
- 移动位置明确以操作前目标链为准；合链保留目标链身份，切链的新身份/期由上层授权提供。不增加重编号、自动改期、资源生成或隐式接受。
- `NumericChainIndex` 按正式代次建立链长、首尾、稳定身份二分索引；节点/原单位置仍直接引用 `NumericPlan` 原权威数组，不创建重复位置台账。
- 架构仅精确允许此模块的 NumPy/Numba，新增负例继续拒绝相似模块、SciPy、pandas、测试依赖及基线常量。未新增依赖。
