## 文件使用

- `stage_04_local_pair/report.json`：两轮状态、耗时、实际检查数、日志与 CSV 校验、结果比较及数据库未变证明。
- `stage_04_local_pair/request.json`、`rules_snapshot.sqlite3`、`service.yaml`：本次实际请求与配置快照。
- `off/response.json`、`on/response.json`：两轮实际公开响应；`metrics.json` 保存各轮完整汇总。
- `off/console.log` 是验证工具捕获的控制台输出，不表示服务开启了文件诊断。
- `on/diagnostics/service.log` 和 `on/diagnostics/runs/<请求标识>/<运行时间_后缀>/`：正式服务能力生成的共享日志与全部诊断资料。
- `candidate_rows.csv` 是完整诊断候选，保持原链序和节点顺序；不可发布时不能用于回写。Excel 按 UTF-8 导入，订单号选择文本。

本次文件包含业务订单，仅本地保存，不自动上传或随 Windows 发布包分发。
