## 2. 实施口径与不变项

已确认业务原则：**计算开始时间 ≥ 本单当前工序最早开始时间，不自动等待；不满足时不得发布。**

计划按设计第 14 节建议安排：缺失真实单时间前置报错；新请求版本 `v7-month-solve-v3`、订单字段 `earliest_start_at`；按真实排产节点计违规数、按提前秒数计严重度；在既有搜索中修复提前开工。上述是本计划采用的建议，不新增业务例外；用户批准按本计划实施后执行，若改变口径先修文档。

| 规则要点 | 实施必须保持的口径 | 设计依据 |
|---|---|---|
| 比较时刻 | 比较节点开始，不是完成；等于下界合格 | 第 3～4 节 |
| 精度与严重度 | 输入北京时间到秒；累计沿用整数毫秒；提前 1 毫秒计违规。严重度为提前秒数，内核整数贡献为提前毫秒乘 1000，检查溢出 | 第 4～5 节 |
| 时间累计 | 从本次开始累加所有节点用时，跨小辊期和大辊期均不重置；不得插入等待或偷移开始时间 | 第 4、8 节 |
| 真实与拆单 | 普通真实材、真实过渡材和每个拆片都检查；拆片按来源索引继承下界 | 第 6 节 |
| 虚拟材 | 生成型虚拟材不检查来源下界，但用时照常累计；不得为了耗时间新增虚拟用途 | 第 6、9 节 |
| 缺失时间 | 启用时拒绝缺失；不补零、不用交期或其他工序时间替代；停用时不强制存在，有值仍校验格式 | 第 6～7 节 |
| 评价 | 纳入九项中的禁止数量和严重度，不加第十项，不改目标顺序和其他硬约束 | 第 5、9 节 |
| 数值与缓存 | 任务入口一次标准化；全方案时间扫描；不把新规则塞进规格矩阵或只按链内容缓存 | 第 8 节 |
| 发布与导出 | 零禁止违规及现有审核通过才能回写；当前步骤全部订单、全部列导出语义不变 | 第 7、10 节 |
