当前并非没有最早开工评价，而是总质量改善仍可能容纳新的借早问题。例如原方案有 A、B 两个提前节点，候选消除两者，却新借入一个未就绪的 C，禁止数量可能从 2 降到 1。本文要求 C 的新借入单独满足时间条件，不能由其他位置的改善抵消。

不得以加大惩罚权重替代此准入条件，也不得向 `reject_prohibited_kinds` 简单追加整项 `EARLIEST_START`，要求全候选一次消除所有历史提前。

## 3. 术语、时间与索引

### 3.1 未来借入按最终候选期间定义

令 `p_src(i)` 为真实节点的来源期间索引，`p_old(i)`、`p_new(i)` 分别为当前方案和候选中的归属期间索引：

```text
候选中属于未来借入：p_new(i) < p_src(i)
```

比较项目权威期间顺序索引，不比较月份字符串、交货日期或今天日期。来源 P2、候选 P0 是借入；来源 P2、候选 P2 是本期；来源 P0、候选 P2 是延后，仍交原有期间规则处理。

必须在变化链归属重算后检查。不能仅判断描述的 source/target 链原期间，也不能仅看主动搬移的订单。目标链因加入早期订单而整体归属提前时，其留在原位的远期订单同样属于新的借入。

### 3.2 时间采用同一完整候选评价结果

全部时刻均为相对 `schedule_start_at` 的整数毫秒。设最早下界为 `r(i)`，实际节点用时为 `d(i)`，则：

```text
s_new(i) = candidate_ends[candidate_flat_position(i)] - d_new(i)
s_old(i) = current_ends[current_flat_position(i)] - d_old(i)
early(s, r) = 0                         当 s >= r
              checked_sub(r, s)        当 s < r
E_new(i) = early(s_new(i), r(i))
E_old(i) = early(s_old(i), r(i))
```

`candidate_ends` 取本次完整候选摘要，`current_ends` 取绑定当前方案的评价；新动态节点从私有数值列读取实际工时。正式提交复核使用物化方案与其对应评价，不能混用上一代数组。

开始等于下界合格，提前 1 毫秒也不合格。负下界合法，不先取显示秒数或进行四舍五入；合法零毫秒拆片仍检查开始时刻。减法和提前量计算使用既有检查算术，分支后才相减，避免无必要的溢出。

跨链、跨大辊期连续累计，不能重置到月初。禁止 `s=max(s,r)`、偷偷后移整次开始时间、改原单下界、放大工时或专门增加虚拟材料来消耗时间。

### 3.3 三类索引不得混用

| 索引 | 读取对象 |
|---|---|
| 节点行号 `row` | 节点用时、角色、来源索引、来源期间及拆片信息 |
| 原始来源索引 `source` | 原单最早开工下界和存在标记 |
| 方案展开位置 `flat_position` | 当前或候选结束时间数组 |

候选按最终视图逐链逐节点扫描，展开位置同步递增。旧位置由当前计划已有索引换算；换算必须遵守 `row_to_position` 实际定义，不能未经确认将其同时当链内位置和全局位置。读取旧位置前先检查节点行号与映射有效性，禁止让 `-1` 变成 NumPy 最后一项索引。

普通真实材、真实过渡材与合法拆片均按来源索引取下界，不以钢种名或订单号前缀豁免。生成型虚拟材本身不查来源下界，但其实际工时已包含在候选结束时间中。

## 4. 时间准入决策

### 4.1 新增或加深借入：必须就绪

候选节点为未来借入，且满足以下任一条件时，要求 `s_new(i) >= r(i)`：

- 当前方案中不存在对应旧节点，但该节点属于现有流程合法产生的真实拆片。
- `p_new(i) < p_old(i)`，即从当前归属进一步借到更早期间；从本期首次借入也包含在内。

没有旧位置不是任意放行或任意创建真实订单的依据。当前任务里已退休的原单行、失效片段或未知行号不能冒充新增合法拆片；来源与谱系仍由既有结构、资源和拆单授权检查约束。若无法解释旧位置缺失，走错误路径。

本条件检查所有新成为借入的节点，包括目标链中没有被显式搬移的节点。未就绪则拒绝当前候选，原因建议为 `future_borrow_before_earliest`；换一个合法的较晚位置后可以再次尝试，不永久封禁该订单或工艺边。

### 4.2 既有借入：提前时长逐节点不恶化

候选中仍属于未来借入、有有效旧节点位置、且没有借到比原归属更早的期间时，要求：

```text
E_new(i) <= E_old(i)
```

这是本设计新增的动作保护，不是当前既有行为。它针对每个节点，而不是只比较提前节点总数或总时长；另一个节点的改善不能抵消此节点的恶化。

| 变化 | 本保护结论 |
|---|---|
| 原提前 2 小时，候选提前 1 小时 | 允许继续进行其他接受检查 |
| 原提前 2 小时，候选仍提前 2 小时 | 不因旧问题未清零而拒绝；仍须完整质量严格改善 |
| 原合格，候选提前 30 分钟 | 拒绝 |
| 原提前 1 小时，候选提前 2 小时 | 拒绝 |
| 开始时刻变早，但前后都已就绪 | 允许，不是全面禁止已借入订单前移 |
| 从 P0 归还至 P1、来源仍为 P2 | 仍是借入；没有加深借入，但提前量不得增加 |
| 归还至来源期间，不再属于未来借入 | 不再受本项借入保护；原最早规则、期锁和质量比较继续执行 |

拒绝原因建议为 `existing_future_borrow_worsened`。允许通过本检查并不代表候选最终被接受；原完整质量与其他保护全部保留。

逐节点不恶化会主动收紧部分原来可进行的指标交换，也可能限制需要先加重某个既有借入问题的路径。本项选择该保守口径，不默默引入随机接受或例外配额。第四项的修复仍可沿不恶化或改善的中间状态推进；不保证所有问题都可由现有邻域解决。

### 4.3 总决策顺序

```text
规则停用或未配置：跳过本项，保持原行为。
对候选最终序列中的每个真实节点：
  候选归属不早于来源期间：不受本项保护，继续原有规则。
  候选属于借入：
    新合法拆片没有旧位置，或候选归属早于旧归属：必须已就绪。
    否则：候选提前时长不得大于旧提前时长。
全部受保护节点通过后，候选才满足借入时间准入。
```

启用判断依据编译程序中的 `NumericRuleKind.EARLIEST_START`，不依据可配置 `rule_id` 字符串或响应文案。输入缺下界、源索引非法、时间越界不是普通未就绪，不能静默跳过、默认零下界或伪装成正常拒绝。

## 5. 检查位置与检查范围

### 5.1 首版使用完整候选之后的精确检查

拟调用链：

```text
原候选生成与原扣额位置
  → 原连接修复与合法动态资源派生
  → 重算归属、期间排序及期锁处理
  → 原完整评价，得到 summary.quality 与 summary.ends
  → 原候选有效性、预算、严格质量改善及其他规则保护
  → 新增借入时间准入
  → 物化正式方案和评价
  → 同一保护复核
  → 唯一正式状态提交
```

首版接在 `consume_candidate_result()`，覆盖首轮、拆单重放、后置精修，以及逐条或批量预计算后实际消费的候选。只对仍可能被接受的候选进行新增扫描，不在各个借单循环中分别复制规则。

`NumericSearchState.commit()` 在任何状态写入之前复用同一数值判断复核。消费时的不满足是正常候选拒绝；若绕过消费保护的候选到提交处仍不满足，应沿现有内部契约错误方式拒绝提交，保持原状态不变，不能把它降为业务警告后继续写入。

消费与提交允许分别传入候选视图、正式计划的数值读取适配，但公式、分类与判定只保留一个权威实现。不得新建第二套生产时钟或重复评分程序。

### 5.2 不在修复前按旧位置时间永久过滤

假设最早开工为 11:00、原插入边界为 10:40，工艺连接确实需要一段合法过渡材、实际用时 20 分钟。完整候选中订单恰好 11:00 开始，应允许通过本检查。桥接前直接判定 `10:40 < 11:00` 会误删这一候选。

反向也成立：移走源链节点、移除旧桥接、重算期间及链序，都可能使实际位置早于旧估计。因此不按原 target 位置或原链开始时刻代替最终候选时刻。后续只有存在性能证据并能证明不会误删可行候选时，才另行设计安全的前置过滤；本版不修改候选枚举顺序。

### 5.3 扫描全部候选真实借入节点，不依赖 affected_rows

`affected_rows` 不是所有时间变化节点的全集：部分动作只登记搬移节点或新增动态行。完整候选中还可能出现目标链原有节点新变借入，以及前缀变化导致未移动的后续借入节点提前。

首版沿最终视图扫描全部节点，对其中的真实借入节点执行保护。即使动作名为整链调序、切链或桥接回收，也不能因“不叫借单”而跳过。

例：Y 已借入 P0，最早 11:00、原开始 12:00。回收前面的桥接材后，Y 未被搬动但开始变为 10:30，应按既有借入恶化拒绝。反之，仍在 11:00 或之后开始则不应误拒。

## 6. 数据、动态资源与正式状态保护

检查输入必须绑定同一当前任务、当前方案代次、规则程序和当前评价，以及本次候选视图与摘要。批次中较早候选一旦被接受，后续旧代次结果不能再按新当前方案提交；沿用现有 `require_current()`、视图 epoch 和提交身份保护。

旧节点通过稳定行号和有效映射寻找，不通过 `source_order_id` 合并全部拆片。一个原单的多个片段可能处于不同时间位置，必须分别比较。原单最后完成时间用于原交期口径，不能替代各片开始时间。

候选私有行通过现有基础列加私有扩展列读取；正式物化后使用其合法追加行和对应评价。新增片段从来源继承下界，在候选中仍为未来借入时按新增借入处理；归还来源期的片段继续接受原时间、守恒与授权检查。

本项不取消已有来源/重量/工时守恒、非空真实链、拆单授权、目标期间锁、虚拟材用途和比例限制。缺少来源位置、下界或有效时间摘要不能通过“按新节点处理”绕过正确性校验。

仅消费检查通过不允许提前修改当前状态、正式虚拟序列或拆单序列。正式物化与复核失败、取消或预算耗尽时，保留原 accepted state；不回写半成品候选。

## 7. 拟修改的代码边界

| 模块 | 拟职责 | 首版限制 |
|---|---|---|
| 新增 `_numeric_borrow_readiness.py` | 使用当前/候选数值位置、时间和期间，执行借入分类及分步保护，返回数值状态和拒绝定位 | 名称为拟定，不是当前已有文件；不解析日期、不构造业务节点、不增加依赖 |
| `_numeric_search.py` | 公共消费调用、拒绝统计、正式提交复核 | 不改候选生成、九项严格改善和其他规则保护，不将保护本身记为一次搜索动作 |
| `tests/core/test_numeric_borrow_readiness.py` | 新增保护函数与消费/提交控制的功能测试 | 只测试新增行为，不要求全局或联合环境作为前置 |
| 专项后续记录 | 实际实现范围、测试结果与已知限制 | 不提前填写测试数量、代码 SHA 或真实收益 |

首版不必修改 `_numeric_candidate_kernel.py`、`_numeric_batch.py` 的计算协议；复用已经产生的完整时间结果。实现中如需对公共入口传参进行最小适配，应保持原单/批量流程一致，不将同一业务判断分别下沉到多个动作。

辅助结果应区分：完整通过、完整业务拒绝、尚有工作、取消以及数值/结构错误。拒绝定位至少能给出节点、来源、候选链位置、前后期间及时间；具体函数签名和数组布局在代码阶段按项目风格确定，不把本文的概念字段当作已存在接口。

A1 的链阈值 `R(L)` 可帮助理解某段的就绪时刻，但本项不能简单调用它要求候选整链全部就绪，否则会把旧提前节点的渐进修复一并拒绝。允许共享列访问与检查算术，不混淆初始布局和搜索差量准入职责。

## 8. 性能、预算与统计

每次保护至多扫描候选 n 个节点，旧位置使用当前方案既有索引，首版时间复杂度 O(n)。无需为拒绝候选物化完整领域方案，也不重复累计一套新时钟。只在原质量等前置条件通过后执行，提交复核只针对即将正式接受的方案；实际成本待新增功能测量，不预先宣称可忽略。

使用现有 NumPy 数值数组和 Numba 检查原语，扫描按有界节点批次返回。消费层在步骤之间及进入正式提交前检查同一个运行预算和取消；不另起计时、不增加总预算，不把未完成扫描当作通过。提交边界所需的预算传递只能沿用同一任务预算，不能形成第二份独立额度。

保持原候选扣额位置和含义。新增保护不再额外扣一次候选额度，完整评价已经完成的候选仍按原口径计入完整评价数；被保护拒绝不增加接受数、虚拟序列或拆单序列。

统计只在实际消费时计数，不在批量推测计算时先记正式拒绝。未消费、旧代次作废或取消的结果分开处理；提交复核不重复累加消费计数。前置质量检查已经拒绝、因而没有执行本保护的候选，不伪装成借入时间拒绝。

## 9. 诊断与评分边界

建议任务内记录 `checked`、`passed`、`rejected_new_or_deeper_borrow`、`rejected_existing_borrow_worsened`、扫描节点数及耗时。命名和承载位置应复用既有搜索诊断风格，不新增公共请求字段、结果枚举或必填 `RunManifest` 字段。

两个业务拒绝原因：

| 原因建议键 | 含义 |
|---|---|
| `future_borrow_before_earliest` | 新增/加深借入的节点在候选实际开始时尚未就绪 |
| `existing_future_borrow_worsened` | 已有借入节点的提前时长比当前方案增加 |

拒绝定位包括动作、当前代次、节点与来源、来源期间、旧/候选归属期间、旧/候选开始偏移、最早下界和前后提前毫秒。无旧节点时旧时间明确为空，不能填零。热路径返回数值定位，业务文本在低频诊断边界生成。

以汇总和有限样例为主，不逐候选打印完整订单。默认可在首个拒绝节点处停止，日志明确这只是首个拒绝见证，不冒充全部被影响订单清单；不把候选拒绝次数混称为最终提前订单数。

这些原因仅表示动作没有被接受，不追加成另一条方案违规，不重复增加禁止数量或严重度。正式最早开工违规、九项质量和最终审核仍取原权威评价。新增保护不重定义回写资格，也不据此把可回写结果称为全部工艺合规。
